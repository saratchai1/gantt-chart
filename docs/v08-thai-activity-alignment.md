# Baseline v0.8 — การปรับกิจกรรมและชื่อเนื้องานเป็นภาษาไทย

## วัตถุประสงค์

การปรับปรุงรอบนี้ตอบข้อเสนอแนะให้ชื่อกิจกรรมและลำดับหมวดงานอ่านเป็นภาษางานก่อสร้างไทย และจัดกลุ่มให้สอดคล้องกับระดับความละเอียดของแผนงานตัวอย่าง โดยไม่เปลี่ยนรหัสกิจกรรม วันที่ ระยะเวลา ความสัมพันธ์ก่อน–หลัง หรือผลการคำนวณ CPM ของ Baseline v0.7

## หลักการใช้แผนงานตัวอย่าง

ไฟล์ `26.08.17 แผนงานก่อสร้างห้วยขาแข้ง หลัก.pdf` ใช้เป็นมาตรฐานด้าน

- โครงสร้าง `Zone → อาคาร/พื้นที่ → หมวดงาน → กิจกรรมย่อย`
- คำเรียกหมวดงานก่อสร้าง
- ระดับความละเอียดของกิจกรรม

ตัวอย่างกิจกรรมที่นำมาใช้เป็นมาตรฐานคำเรียก ได้แก่

- งานโครงสร้าง
  - งานปรับบริเวณและปักผัง
  - งานก่อสร้างฐานราก
  - งานโครงสร้างคอนกรีตเสริมเหล็กและงานเหล็กรูปพรรณ
- สถาปัตย์
  - งานหลังคา
  - งานผนังและผิวผนัง
  - งานตกแต่งผิวพื้น
  - งานฝ้าเพดาน
  - งานประตู–หน้าต่าง
  - งานสุขภัณฑ์และอุปกรณ์
  - งานทาสี
  - งานเฟอร์นิเจอร์
- งานระบบไฟฟ้าและสื่อสาร
- งานระบบสุขาภิบาลและป้องกันอัคคีภัย
- งานระบบปรับอากาศและระบายอากาศ
- งานครุภัณฑ์
- งานภูมิทัศน์
- งานระบบพิเศษ

**ไม่ได้คัดลอกระยะเวลา วันที่เริ่ม–สิ้นสุด หรือลำดับ Logic ของแผนงานตัวอย่างมาใช้** กรอบเวลา 1,200 วัน งวดงาน 1–497 ขอบเขตพื้นที่ และ Logic ยังคงอ้างอิงแผนที่ 1–16 และสมมติฐาน Baseline ของโครงการเรา

## โครงสร้างข้อมูลภาษา

ทุกกิจกรรมเก็บข้อมูลสองภาษาเพื่อให้ตรวจสอบย้อนกลับได้

| ฟิลด์ | ความหมาย |
|---|---|
| `activity_name` | ชื่อภาษาไทยที่ใช้แสดงผลเป็นหลัก |
| `activity_name_th` | ชื่อภาษาไทย |
| `activity_name_en` | ชื่อภาษาอังกฤษเดิมก่อนปรับ |
| `work_category_th` | หมวดงานหลักภาษาไทยสำหรับจัดกลุ่ม Gantt |
| `discipline_th` | คำแปลสาขางานเดิม |
| `discipline_en` | สาขางานภาษาอังกฤษเดิม |
| `building_area` | ชื่อพื้นที่ภาษาไทยที่ใช้แสดงผลเป็นหลัก |
| `building_area_th` | ชื่อพื้นที่ภาษาไทย |
| `building_area_en` | ชื่อพื้นที่ภาษาอังกฤษเดิม |
| `translation_status` | วิธีที่ใช้กำหนดชื่อภาษาไทย |
| `translation_note` | หมายเหตุการแปลและการทบทวน |

รหัสกิจกรรม (`activity_id`) และ WBS ไม่เปลี่ยน เพื่อรักษา Dependency, CPM และประวัติการตรวจสอบเดิม

## การจัดกลุ่ม Plan 01

### งานอาคาร

กิจกรรมเดิมของแต่ละอาคารถูกจัดเข้าหมวดมาตรฐาน ดังนี้

| กลุ่มรหัสกิจกรรม | หมวดงานภาษาไทย |
|---|---|
| `SUR`, `EXC`, `BLI`, `RBF`, `FMF`, `HOLD`, `FND`, `GB`, `FRM`, `ROOF` | งานโครงสร้าง |
| `ENV`, `EWALL`, `PART`, `WFIN`, `DRW`, `CEIL`, `FLR`, `PNT`, `SAN`, `FURN` | สถาปัตย์ |
| `ELE1`, `ELE2` | งานระบบไฟฟ้าและสื่อสาร |
| `PLB1`, `PTST` | งานระบบสุขาภิบาลและป้องกันอัคคีภัย |
| `HV1`, `HV2`, `HTST` | งานระบบปรับอากาศและระบายอากาศ |
| `ICT1`, `ICT2`, `ITST` | งานระบบพิเศษ |
| `EXT` | งานภูมิทัศน์และงานภายนอก |
| `PRECOM`, `FUNC`, `COMM` และ Test Packs | งานทดสอบและเดินระบบ |
| `SNAG`, `CORR` | งานตรวจสอบและแก้ไขข้อบกพร่อง |
| `ASB`, `HO` | งานแบบก่อสร้างจริงและส่งมอบ |

กิจกรรม `SAN` หรือการติดตั้งสุขภัณฑ์และอุปกรณ์ถูกจัดไว้ใต้ **สถาปัตย์** ให้ตรงกับกิจกรรมในภาพตัวอย่าง ส่วนงานท่อ ระบบน้ำ ระบายน้ำ และดับเพลิงระยะที่ 1 รวมถึงการทดสอบระบบ ยังคงอยู่ใต้ **งานระบบสุขาภิบาลและป้องกันอัคคีภัย**

กิจกรรมที่ละเอียดกว่าตัวอย่าง เช่น เหล็กเสริม แบบหล่อ จุดพักตรวจก่อนเทคอนกรีต งานระยะที่ 1/2 และ Test Pack ยังคงไว้ เพราะเป็นรายละเอียดที่จำเป็นต่อ Logic และการควบคุมงานจริง

### งานภายนอกและภูมิทัศน์

งานทางเข้า จุดรับส่ง สนามหญ้า ลานจอดรถ ผังบริเวณ และพื้นที่ศึกษาธรรมชาติ จัดกลุ่มเป็น

- งานสำรวจและปักผัง
- งานโครงสร้างและงานโยธา
- งานระบบระบายน้ำ
- งานระบบภายนอก
- งานระบบไฟฟ้าและสื่อสาร
- งานภูมิทัศน์และงานภายนอก
- งานสิ่งแวดล้อมและฟื้นฟู
- งานตรวจสอบและแก้ไขข้อบกพร่อง
- งานส่งมอบ

การจัดกลุ่มนี้ใช้ขอบเขตงานภายนอกของแผนเรา ไม่ได้เพิ่มงานหลังคา ผนัง หรือกิจกรรมอาคารให้กับพื้นที่ที่เอกสารต้นทางไม่ได้ระบุว่าเป็นอาคาร

### แพสูบน้ำดิบ

แพสูบน้ำดิบยังคงใช้ลำดับเฉพาะงานใกล้น้ำ ได้แก่

- ตรวจสภาพก่อนเริ่มงาน
- ความพร้อมกู้ภัยและช่วยชีวิต
- ทางเข้าพื้นที่ยกและขนถ่าย
- ผลิต/ประกอบโครงสร้างลอยน้ำ
- แผนยกและติดตั้งแพ
- ท่อ วาล์ว ปั๊ม ไฟฟ้า ระบบควบคุม และเครื่องมือวัด
- เตรียมทดสอบและทดสอบการทำงาน
- ตรวจสภาพหลังงานและฟื้นฟูพื้นที่
- ส่งมอบ

## Plans 02–16

ชื่อกิจกรรมสนับสนุนถูกปรับเป็นภาษาไทยตามศัพท์ของแต่ละแผน เช่น

- การตรวจวัดผลงานและรับรองการเบิกจ่าย
- การระดมและปรับสมดุลกำลังคน
- การจัดหา อนุมัติ ผลิต ขนส่ง ตรวจรับ และปล่อยติดตั้งวัสดุ
- Method Statement / ITP / Hold Point / NCR
- JSEA / ใบอนุญาตทำงาน / LOTO / งานบนที่สูง / งานยก / งานใกล้น้ำ
- การควบคุมจราจร สิ่งแวดล้อม เอกสาร ความก้าวหน้า BIM และ Digital Twin
- โปรแกรมประยุกต์และ AI
- คาร์บอนฟุตพริ้นท์
- การคุ้มครองพื้นที่มรดกโลก

คำย่อมาตรฐาน เช่น WBS, BOQ, BIM, ITP, NCR, JSEA, PTW, LOTO, CDE/EDMS, AIM และ Digital Twin ยังคงไว้เมื่อจำเป็นต่อการสื่อสารทางวิชาชีพ
